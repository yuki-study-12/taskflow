# TaskFlow 利用説明書

## 1. はじめに

TaskFlow は、チームでプロジェクトのタスクをカンバンボード形式で管理できるWebアプリケーションです。この説明書では、実際の画面操作にそって使い方を説明します。

## 2. アカウント登録

1. ブラウザで TaskFlow を開くと、未ログインの場合はログイン画面が表示されます。
2. ログイン画面下部の **「アカウントを作成」** リンクをクリックして、アカウント登録画面（`/register`）に移動します。
3. 以下を入力します：
   - **表示名**（1〜50文字）
   - **メールアドレス**（有効な形式である必要があります）
   - **パスワード**（8〜100文字）
4. **「登録」** ボタンを押します。
5. 登録に成功すると、自動的にログインした状態でダッシュボード画面に移動します。

> 通信エラーが出る場合は、バックエンド（`TaskFlow.WebAPI`）が起動しているか確認してください。

## 3. ログイン

1. ログイン画面（`/login`）でメールアドレスとパスワードを入力します。
2. **「ログイン」** を押すとダッシュボード画面に移動します。
3. ログイン状態はブラウザに保存され、既定で60分間有効です。60分を過ぎると再ログインが必要になります。

## 4. ダッシュボード画面

ログイン後に表示されるトップ画面です。

- 左側: 自分が参加している**プロジェクト一覧**（プロジェクト名・自分のロール・説明が表示されたカード）
- 右側: 自分が**担当しているタスク一覧**（全プロジェクト横断）。タスク名をクリックすると、そのタスクが属するプロジェクトのボード画面に移動します。
- 画面上部の **「+ 新規プロジェクト」** ボタンから新しいプロジェクトを作成できます。
- 画面上部には通知ベル（🔔）があり、未読の通知件数が赤いバッジで表示されます。
- 左サイドバーからログアウトできます。

## 5. プロジェクトの作成

1. ダッシュボード画面の **「+ 新規プロジェクト」** ボタンを押します。
2. モーダルが開くので、**プロジェクト名**（200文字以内）と**説明**（1000文字以内）を入力します。
3. **作成** すると、あなたがそのプロジェクトの **Owner（オーナー）** として自動的に登録されます。

## 6. カンバンボードの操作

ダッシュボードのプロジェクトカードをクリックすると、そのプロジェクトのボード画面に移動します。

### 6.1 ボードの作成（初回のみ）

プロジェクト作成直後はまだボードが存在しません。「ボードを作成」ボタンを押すと、ボードと **ToDo / 進行中 / 完了** の3つの列が自動的に作成されます。

### 6.2 タスクカードの表示

各列にタスクのカードが並びます。カードには以下が表示されます：
- タスクタイトル
- 担当者の割り当て状況（「未割り当て」/「担当者あり」）

優先度・期限はカード面には表示されず、詳細画面でのみ確認できます。

### 6.3 タスクの詳細確認・編集

カードをクリックすると詳細モーダルが開き、以下を編集できます：

| 項目 | 内容 |
|---|---|
| タイトル | テキスト入力 |
| 説明 | テキスト入力 |
| 期限（DueDate） | 日付選択 |
| 優先度 | 低 / 中 / 高 / 緊急 から選択 |
| 担当者 | プロジェクトメンバーから選択（「未割り当て」も選択可） |

**編集内容は自動保存されます**（入力を止めてから約0.8秒後）。画面右上に「編集中...」→「保存中...」→「保存済み」というステータスが表示されます。保存ボタンは無く、**「閉じる」** ボタンで画面を閉じると、未保存の変更があれば自動的に反映されます。

### 6.4 ドラッグ&ドロップでのタスク移動

タスクカードは、マウスでドラッグして別の列に移動したり、同じ列内で並び替えたりできます。移動は即座にサーバーに反映され、同じボードを見ている他のメンバーの画面にも**リアルタイムで反映**されます（ボード画面上部の「リアルタイム同期中」表示が緑色のときは正常に接続されています）。

### 6.5 コメント

タスク詳細モーダルの下部にコメント欄があります。
1. テキストエリアにコメントを入力します（2000文字以内）。
2. **「投稿」** ボタンでコメントを追加します。
3. 投稿されたコメントは、投稿者名・投稿日時とともに一覧表示されます。

コメントを投稿すると、そのタスクの担当者と作成者（自分以外）に通知が届きます。

## 7. 通知機能

画面上部の通知ベル（🔔）をクリックすると、通知の一覧が表示されます。

| 通知の種類 | 表示ラベル | 内容 |
|---|---|---|
| タスクアサイン | タスクアサイン | 自分がタスクの担当者に設定された |
| コメント | コメント | 自分が担当/作成したタスクにコメントが付いた |
| メンバー招待 | メンバー招待 | プロジェクトに招待された |

- 未読の通知は太字で表示されます。
- 通知をクリックすると既読になり、該当のプロジェクトのボード画面（タスク関連の通知の場合は該当タスクの詳細モーダルが自動的に開いた状態）に移動します。
- **「全件既読」** リンクで、すべての通知をまとめて既読にできます。
- 新しい通知が届くとリアルタイムで未読件数バッジが更新されます。

## 8. マイタスク一覧

ダッシュボード右側の一覧です。自分が担当者に設定されているタスクが、所属プロジェクトをまたいで一覧表示されます。タスク名をクリックすると該当プロジェクトのボードに移動します。

## 9. ログアウト

左サイドバーの **「ログアウト」** ボタンを押すと、ログイン情報が削除されログイン画面に戻ります。

---

## 10. 現時点でWeb画面から操作できない機能について

以下の操作は、この画面（Web UI）からはまだ行えません。開発者向けのAPI画面（開発環境で `/openapi` から開けるSwagger UI）を使って直接操作する必要があります。今後の画面追加が予定されている機能です。

- プロジェクトへのメンバーの招待・ロール（Admin/Member）変更・削除
- プロジェクト名/説明の編集、プロジェクトの削除
- 新しい列（カラム）の追加
- タスクの新規作成・削除
- コメントの削除

メンバー管理などが必要な場合は、開発担当者にご相談ください。
